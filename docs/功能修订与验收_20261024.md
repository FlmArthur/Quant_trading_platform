# 功能修订与验收（2026-10-24）

## 对应用户反馈

1. 修复长期区间请求被静默截断的问题。AKShare新浪分钟接口不能按日期回溯多年；覆盖不足默认失败，只有明确勾选部分获取才保存。旧的两个2023请求数据版本已标记未覆盖区间，价格文件及哈希保持原样。已接入可配置的Tushare历史分钟入口，但当前没有有权限账号，真实多年数据尚未取得。用户已确认暂时没有长期数据来源，后续确定来源。
2. 数据版本支持删除、回收站恢复；活动训练引用数据时先停止任务。
3. 模型实验、策略支持删除及恢复。保留依赖文件以便既有会话、报告继续读取。
4. 发布改为配置窗口，可选择名称、独立时长模型、固定持有期与止损；成功显示版本标识，失败显示具体原因。已在页面验证发布、删除、恢复。
5. 模拟与回测支持历史开始日期、兼容数据版本选择。回放只揭示已经到达的历史。自动模型必须早于回放时点完成训练与验证。逐条预测在完整标签窗口到达后才计入方向准确率、时长MAE与RMSE，支持只看已核验记录。
6. 模拟交易增加价格/历史分段/拐点候选图、模型概率变化、当前输入、卷积通道与LSTM门均值、模型版本和执行规则解释。拐点为派生候选而非独立的拐点分类器，概率为未校准方向输出；时长回归不虚构概率。
