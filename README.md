# 趋势研究所

基于两篇论文方法的本地量化交易教学平台。包含真实的 PyTorch CNN / LSTM / 并联融合训练、DEAP 强类型随机多目标遗传规划、逐层数值观察、AKShare 获取、文件导入、样本外回测和模拟账户。

## 启动

需要 Python 3.11 以上、Node.js 20.19 以上（或22.12以上）。macOS可双击 `start.command`，或在项目目录运行：

```sh
./start.sh
```

首次安装依赖需要网络。打开 [本地平台](http://127.0.0.1:8765)。程序只监听本机，定位为单用户研究软件；不连接真实券商，不是面向公网的多租户系统。

开发时分别运行：

```sh
.venv/bin/python -m uvicorn backend.api:app --host 127.0.0.1 --port 8765
```

```sh
npm --prefix frontend run dev
```

开发页面位于 http://127.0.0.1:5173 。生产页面由 Python 服务直接提供。依赖锁定在 `requirements.lock` 和 `frontend/package-lock.json`；精确复现本机环境可使用 `.venv/bin/python -m pip install -r requirements.lock`，其他系统优先用 `requirements.txt` 安装兼容轮子。

## 完整操作流程

1. 数据中心选择 AKShare 在线获取，或上传 CSV、TSV、XLSX。
2. 论文方法库选择混合神经网络或遗传规划。首次演示可选“教学合成”数据，实际计算仍使用真实算法，但结果不代表市场表现。
3. 实验工作台选择数据、配置训练参数。先检查样本，然后开始训练。神经模型默认独立训练方向和时长两套网络；GP按交易日滚动窗口进化。
4. 使用检查点选择器回看真实激活、LSTM门状态、特征相加或遗传规划树。任务支持暂停、继续、取消，刷新页面不会停止服务端任务。
5. 完成后发布策略。方向模型可单独发布，未配时长模型时明确使用固定12条持有期；默认“方向与时长”实验自动使用两个独立模型。
6. 回测对照使用发布版本和所对应的数据，从模型训练及选参截止之后执行。导出成交CSV。
7. 模拟交易创建自动策略账户或独立手动账户。下一行情成交，回放速度不影响账目；手动委托后须推进下一条行情。
8. 报告中心生成不可变报告快照，下载HTML，可在浏览器打印为PDF。

## 数据格式

推荐UTF-8 CSV（支持中文列名“日期、开盘、最高、最低、收盘、成交量”）：

```csv
timestamp,open,high,low,close,volume,market_close
2024-01-02T09:35:00,3500,3504,3498,3502,12000,3001
2024-01-02T09:40:00,3502,3506,3501,3505,15000,3002
```

至少20条，最多20万条；时间必须唯一，数值必须有效。时间统一为上海时区。缺少open时使用下一条close成交，不伪造开盘价。

论文一使用5分钟IF行情。股票指数日线也可用于明确标识的探索实验。论文二使用日线，需要成交量与至少120条指标预热，外加125日训练窗口和样本外区间。上证指数可通过 `market_close` 同行提供，或在参数中选择单独导入的日频环境数据；缺失日期拒绝训练。去除市场因子需显式勾选25因子消融。

GP基准日默认为论文的2015-01-05，替代数据须显式选择存在的基准日。教学日频示例基准为2021-01-04。分钟示例含50个工作日的合成行情；仅使用工作日近似历法，明确属于教学而非交易所日历。

AKShare提供股票指数日线、期货日线和期货分钟线三个入口；分钟线通常只有近期，接口实际可用区间保存在数据元信息。网络错误、限流或不支持的合约会显示任务失败原因，不回退为合成行情。[AKShare官方期货接口](https://github.com/akfamily/akshare/blob/main/docs/data/futures/futures.md)、[官方指数接口](https://github.com/akfamily/akshare/blob/main/docs/data/index/index.md)。

## 研究与执行约定

- CNN输入业务形状4×5，PyTorch卷积轴为通道5、位置4。两层卷积核1、通道20；LSTM隐藏单元100。投影后相加，优化器Adagrad，论文学习率0.005、批128、65轮。Dropout、L2、ReLU和恒等池化属于明确的实现约定。
- 提供两种样本协议：默认“严格历史前缀”用固定时刻的有界历史构造特征，未来有界窗口只生成训练标签，避免未来端点泄漏；“论文离线分段”对全样本分段，以历史4段预测下一完整段，可比较论文的方向和完整时长实验。后者可能使用事后确认的端点，平台禁止发布为交易策略。两者都记录边界与差异，不能混称为作者数值复现。跨训练/验证/测试边界的标签剔除，阈值只在验证集选择。
- GP使用论文30因子、严格类型、μ+λ父子共同选择、0.7交叉/0.2变异/0.1复制。每代所有候选共享当代随机权重，重新加权原始指标。每预测块独立训练并冻结树，按可用时间加载，不提前使用未来窗口模型。
- 所有基线、FMO、PRMO、RMO可单独运行并比较。普通非强类型GP、RSFGP、自动九宫格敏感性批处理和跨论文组合尚不包含；可手动提交不同配置/种子作为独立实验。
- 回测与交易共用 `trading/engine.py`。收盘产生目标仓位，下一条open成交；没有open则下一条close。多空换仓分平旧开新两笔，手续费与滑点逐笔扣除。止损为收盘触发、下一可用行情执行，区间终点按预定规则平仓。
- 名义本金研究模式按可用资金调整单位数量，不用保证金收益混充论文收益。期货保证金模式要求真实单合约和settlement列、显式乘数、保证金及平今费率；支持逐日结算和保证金强平。主连换月自动映射尚未实现，主连仅可研究回放；请不要把拼接跳变解释为真实可成交利润。
- 夏普使用每日权益收益、252交易日及显式零无风险基准；此项与原论文国债基准有差异。零波动、零回撤显示不可计算；没有预设论文收益率。

## 持久化与恢复

SQLite、行情文件、权重、进化种群和日志全部位于 `var/`（不纳入源码）。通过 `QUANT_DATA_DIR` 可更换目录。定期备份整个目录；停服后拷贝最简单。实验保留源码哈希、数据哈希、配置、随机种子、依赖锁哈希与逐轮检查点。

训练在独立子进程中串行调度。暂停发生在epoch或代数安全边界。服务退出会终止子进程并标记待恢复；在工作台点击继续从最近完整检查点恢复。神经网络恢复优化器及随机状态，GP恢复种群、窗口和随机状态。已完成实验与发布策略不覆盖。

## 增加论文

`research/registry.py` 存放方法元信息和步骤。通过 `register(Method(..., validator=..., trainer=..., predictor_factory=...))` 注册可信Python实现；训练调度、发布和账户自动调用对应函数。前端从方法库加载新增名称。新方法的专有参数和解释面板可在配置schema与组件中添加。

trainer返回 `results`、`artifacts`（每项提供可校验的path）、`training_cutoff`和`deviations`；predictor_factory返回具有 `predict(index)` 方法的对象，输出direction、horizon、as_of、available_at和reason。预测方向仅可为-1、0、1，horizon为正整数。账户与撮合引擎不依赖神经模型或GP内部结构，无需修改。插件只从本地可信源码注册，不接受上传执行代码。

详细需求依据见 `docs/量化交易平台软件开发文档_V1.0.md`。本软件实现课程本地研究闭环；多用户鉴权、交易所全量历法、自动换月和公网部署不在当前版本中。

- 发布策略打开配置窗口，可选版本名称、单独的时长实验、固定持有期和止损。发布成功显示版本标识并刷新列表；失败原因直接显示在窗口。若需要“CNN判断方向、LSTM判断时长”，分别训练CNN方向实验、LSTM时长实验，使用相同数据及标签协议，再在发布窗口组合；混合模型原有的两路并联结构仍如实标识。

- 模拟交易逐条记录实际模型预测，与交易的持有期执行分开。价格图显示已到达价格、已知历史分段、候选拐点；解释卡显示方向概率、阈值、预计时长、模型版本及当前真实价格输入、卷积通道平均激活、LSTM门均值。拐点候选是“末段已知方向与预测方向不同”的派生信号，当前并未训练独立的拐点概率分类器。
- 模型输出概率未校准，不能解释为保证正确的概率。时长模型为回归模型，不伪造时长置信概率。预测记录须等完整标签窗口到达后才核验，方向与时长按训练的首段标签协议比较，展示方向准确率、时长MAE/RMSE与历史记录；逐条标签有重叠，不作为独立样本显著性结论。数据末尾未到期的预测保持“待揭晓”。

### 回测和模拟历史管理、预测点详情

回测记录列表和模拟交易历史列表均支持逐条删除与回收站恢复。删除正在打开的模拟会话会停止页面回放；后端拒绝继续推进或提交委托，恢复后可按原进度继续。已生成的报告快照与引用数据保留。

历史回放图的候选预测点支持鼠标悬停、点击及键盘聚焦，信息卡显示预测时间、当时价格、方向、上涨/下跌概率、时长、执行阈值、模型标识与已到期的实际核验结果；未揭晓的预测不会显示未来答案。

### 实验工作台的三种计算视图

“卷积观察”“长短期记忆”“特征融合”分别打开独立视图，保持同一检查点和固定样本：

- 卷积页可切换第一/第二层、输出通道及4个位置，显示输入×权重、偏置、ReLU和实际激活，支持逐位置播放。
- LSTM页可切换4个时间步和任意隐藏单元，显示四个门及 `c=f×c_prev+i×g`、`h=o×tanh(c)` 的真实数值，支持时间步播放。
- 融合页可选择任意向量坐标，对照CNN投影、LSTM投影、融合值和输出层贡献，可临时屏蔽卷积通道观察输出变化，再恢复。
- 单CNN或单LSTM基线如实标记未启用分支，不展示成双路融合。旧检查点从原始权重中补读遗漏的展示参数，不覆盖原JSON和模型文件，也无需重新训练。

前端回归检查：`npm --prefix frontend run test:views`。后端新增数值检查覆盖两层卷积、LSTM四步状态更新、融合输出及旧检查点只读补充。

### MACD 传统规则策略

在「模型与策略」创建 MACD 策略版本，选择行情与快线、慢线、信号线周期（默认 12、26、9）。无需训练，可用于回测和模拟交易。EMA 从数据首个收盘价初始化，递推系数为 2/(周期+1)；DIF = 快线 EMA − 慢线 EMA，DEA 为 DIF 的 EMA，柱值 = 2 × (DIF − DEA)。慢线周期加信号线周期减 1 条行情后开始判断。DIF > DEA 时目标为多仓，否则为空仓；按照收盘信号在下一条行情开盘成交，有开盘价时使用开盘价。回放起点之前的数据用于指标预热。可选固定止损在收盘触发并在下一条行情执行。

规则和参数应在测试区间之前确定；如果在整个回测区间上反复调整参数，结果不能视作独立样本外表现。该策略不产生方向预测概率，不支持自动做空。

### 每日预测与观察

「每日预测」按已收盘日线选择同标的、同频率的已发布策略，生成并保存策略信号。可分别开启自动检查：平台运行期间约每 5 分钟检查，通过 AKShare 交易日历确认最近已收盘交易日，并自动获取沪深300、上证指数和深证成指所需日线；当天行情在北京时间 15:30 后使用。数据未更新到已收盘交易日时不生成新判断并自动重试。预测记录可删除并在回收站恢复。

CNN/LSTM 输出是下一段趋势的方向信息，不是下一交易日涨跌预测；STGP、MACD 是目标仓位规则，不是下一日方向概率。策略本身未训练日收益率回归，因此页面另列近 60 个日收益率的均值和 10%、90% 分位数作为历史参考，不是由策略预测的涨跌幅或预测区间。策略建议只是规则对应的模拟仓位提示，不考虑个人持仓。后续结果取兼容行情版本中相同截止收盘价之后的下一条已收盘日线；如果数据缺失交易日，必须先核对数据。记录会标记实际结果出现后才生成的事后判断。

### 道氏理论双指数月线观察

「每日预测」中可创建道氏策略，选择沪深300、上证指数和深证成指日线。每个月采用三份数据的该月最后一条收盘，校验月末日期一致和共同月份连续；自然月结束后才使用该月数据，但系统没有独立交易日历，仍需检查三份数据是否同时缺失月末行情。局部高低点需前后各一个月，因此至少在下一月收盘后才能确认。两个指数同月满足较低高点并跌破前低，才确认向下；反向为确认向上；相同方向持续只计一次，状态保持到反向确认。初始化的共同区间从三份数据都有记录的最早月份开始，可能与参考分享的 1995 年起算历史不同。

策略只用于每日预测中的长期市场状态参考，不构成日涨跌幅或概率预测，也不用于回测和模拟交易。手动预测使用策略创建时关联的固定指数版本；开启自动预测后自动获取最新指数日线，并在记录中保留使用的具体数据版本。自动预测依赖平台保持运行、网络及 AKShare 可用。输入数据和模型状态并不会验证该分享中的历史统计结果。

自动预测可统一设置「按间隔」（1–1440 分钟）或「每天固定时间」（北京时间），每个策略也可单独设置；已有单独保存的时间保持不变。服务运行期间按设置刷新 AKShare 数据，若数据未变化复用已有版本和预测记录。固定时间错过后，当天服务启动会补运行；如果失败，每约 5 分钟重试。固定时间在 15:30 前时只使用此前已经收盘的数据。关闭平台或电脑时任务不会运行。
